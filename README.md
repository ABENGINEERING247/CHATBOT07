# IF_Starter_Project

A small, functional chatbot starter project built with Streamlit. Run it in offline demo mode without credentials, or connect it to an OpenAI-compatible Chat Completions API.

## Features

- Chat-style interface with session-only conversation history
- Offline demo mode that requires no network access or API key
- Optional API connection with configurable base URL and model
- Editable assistant instructions
- Export chat history as a Markdown file
- Clear chat control
- API credentials are entered at runtime and are not written to project files

## Run locally

Python 3.9 or newer is recommended.

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

Choose **Offline demo** to try the interface immediately. Offline replies are illustrative and are not generated by a language model.

## Connect an API

1. Select **OpenAI-compatible API** in the sidebar.
2. Enter the API base URL, model name, and API key.
3. Send a message. The app sends requests to the configured base URL with `/chat/completions` appended when needed.

For OpenAI, the typical base URL is `https://api.openai.com/v1`. You can optionally set `OPENAI_API_KEY` in your environment before starting Streamlit; the app uses it as the initial value for the password field. You can also enter a key directly in the app. Credentials are used in session memory and are not saved to this project. Only connect to API endpoints you trust.

## Project files

- `app.py` — Streamlit application and API client
- `requirements.txt` — Python dependencies
